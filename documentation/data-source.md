## Project Context

This project was developed as a learning and portfolio exercise to demonstrate practical Power BI data modeling skills.

The work focuses on applying concepts including:

- Dimensional modeling
- Star Schema
- Galaxy Schema
- Power Query
- DAX
- Data transformation
- Relationship design
- Row-Level Security
- Data governance
- Semantic modeling

The data model, transformations, relationships, measures, and security design documented in this repository represent my implementation and application of these concepts.
